### How I run the desk

- **Never off air.** Every stream gets a fallback, every deploy gets a rollback.
- **Build for the person in the studio.** If the presenter has to think about the tool mid-show, the tool is wrong.
- **Ship small, ship often.** Short segments, tight transitions.
